# Reps app icon source

Silhouette: [Phosphor Icons — barbell-fill](https://github.com/phosphor-icons/core/blob/main/assets/fill/barbell-fill.svg), MIT, copyright 2023 Phosphor Icons. Original SVG and complete license retained beside this file.

Reps adapts the filled path into two layers (body and outer weights), rotates it −32°, and supplies Icy Cyan/silver gradients. Icon Composer material, lighting and background settings derive from the user-owned Kavi reference tested on iPhone. Sources live in ../RepsIcon.icon; build with scripts/build-app-icon.py using the already-installed Linux actool. No runtime dependency or SF Symbol used.

0.11.12: geometry redrawn as three overlapping groups: front cyan plates, rear silver plates, and a full-length handle underneath. Plate overlap is 16 SVG units at each end. A fine pale stroke defines each edge; native material provides shadows/specular/translucency. No baked blur or pre-masked outer icon border.
